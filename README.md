# Apex Multi-Specialty Medical Institute & Diagnostics

A cutting-edge, high-conversion client acquisition website template designed specifically for advanced clinical care centers and polyclinics covering **Cardiology, Dental Surgery, Obstetrics & Gynecology, Physiotherapy & Sports Rehabilitation, Automated Molecular Labs, and Family Medicine**.

## Key Features
- **Swiss Precision Clinical Aesthetics**: High-contrast Slate Navy (`#0f172a`), Clean Precision Cyan (`#0284c7`), Ice White (`#f8fafc`), and clinical glassmorphic surfaces.
- **Live Emergency & OPD Wait-Time Ticker**: Live status bar displaying on-duty specialists and low average wait times.
- **Interactive Diagnostic Lab Catalog & Doorstep Phlebotomy Dispatcher**: Test selector with walk-in or home blood collection booking and instant WhatsApp dispatch.
- **Interactive Cardiovascular & Metabolic Risk Screener**: 60-second questionnaire providing immediate medical risk scores and priority booking recommendations.
- **Precision Booking Engine**: 3-step appointment scheduling across all 6 departments with real-time slot selection and paperless intake.
- **Floating Emergency & Rapid Care Desk**: Sticky concierge with one-tap emergency call and direct WhatsApp triage link.

## Getting Started Locally

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.

## Deploying to GitHub & Vercel

### Option 1: Direct GitHub Push
```bash
git init
git add .
git commit -m "Initial commit - Apex Medical Institute Template"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/apex-medical-institute.git
git push -u origin main
```

### Option 2: 1-Click Vercel Deployment
1. Push this directory to your GitHub account.
2. In the Vercel Dashboard, click **Add New > Project** and import the repository.
3. Vercel automatically detects Next.js and builds with zero configuration.
